# 应援棒 Web 控制台

用浏览器通过蓝牙控制应援棒配色的网页控制台。不用装 App、不用后端，打开网页就能调色。

> 在线使用：`https://ltykawaii.github.io/`

## 功能

**连接**
- 点「配对」，在浏览器弹出的设备列表里选中你的设备（通常显示为「应援棒控制」）
- 右上角实时显示状态：未连接 / 连接中 / 已连接 / 已断开 / 连接失败
- 设备断开后页面会给出提示，重新配对即可继续

**调色**
- R / G / B 三通道独立调节，范围 0–255
- 滑杆和数字输入框双向联动，改哪边都同步
- 数字框支持键盘微调：`↑` `↓` 步进 1，按住 Shift 步进 10，PageUp / PageDown 步进 10
- 回车确认、Esc 还原；输入超出范围会标红，失焦时自动修正

**预览与预设**
- 顶部色块实时显示当前颜色，同时给出 HEX 和 `rgb()` 两种写法
- 12 个预设颜色：天依蓝、红、橙、黄、绿、青、蓝、紫、粉、白、暖白、关灯
- 当前颜色和某个预设完全一致时，对应按钮会高亮

**发送**
- 点「发送当前颜色」把当前颜色下发给设备

**日志**
- 页面底部有带时间戳的日志，发送记录、设备回执、错误信息用不同颜色区分，可一键清空

**访问密钥**
- 设备有密钥保护，首次连接时会提示输入
- 输过一次后浏览器会记住，之后自动使用
- 密钥只存在你自己浏览器的本地存储里，页面不会把它发往任何服务器

## 使用

1. 用 Chrome 或 Edge 打开页面
2. 点「配对」，在弹窗中选中你的设备
3. 首次连接按提示输入密钥
4. 调好颜色，点「发送当前颜色」

## 浏览器要求

| 浏览器 | 支持 |
| --- | --- |
| 桌面 Chrome / Edge | ✅ |
| Android Chrome / Edge | ✅ |
| iOS Safari | ❌ 全系不支持 |
| Firefox | ❌ 不支持 |

必须通过 HTTPS 或 localhost 访问——GitHub Pages 默认就是 HTTPS。另外配对必须由你手动点击触发，不能用脚本自动完成，这是浏览器的安全要求。

## 部署到 GitHub Pages

1. 把 `web_controller.html` 重命名为 `index.html`（Pages 默认以它作为首页）
2. 推送到默认分支
3. 仓库 **Settings → Pages**，Source 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`
4. 等一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

## 常见问题

- **设备列表里找不到设备**：确认设备处于可被扫描的状态、系统蓝牙已开启，并且没有被其他手机或网页占用（多数蓝牙设备同时只允许一个连接）
- **提示连接失败**：关掉系统蓝牙再打开，重新点「配对」
- **密钥输错了**：按 F12 打开控制台，执行 `localStorage.removeItem('bluetooth_auth')`，然后重新连接
